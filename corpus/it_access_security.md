# IT Access and Security

## Authentication
Passwords must be at least 14 characters long. Multi-factor authentication is mandatory for all remote access.

## Access management
Privileged access is reviewed every quarter. Access of leavers is revoked within 4 hours of termination. USB storage is blocked by default and laptops are fully encrypted.

## Incidents
Security incidents must be reported to security@northwind.example within 1 hour of discovery.
